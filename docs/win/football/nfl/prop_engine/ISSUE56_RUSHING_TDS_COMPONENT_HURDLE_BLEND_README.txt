ISSUE 56 — RUSHING TDS COMPONENT/HURDLE BLEND DIAGNOSTIC

Purpose
-------
The raw component and hurdle model have complementary error profiles:

Raw component, 2024:
- MAE 0.086474: PASS
- improvement 8.649052%: PASS
- Brier 0.046478: PASS
- Poisson 0.424515: PASS
- bias -0.041089: FAIL

Hurdle positive-mean severity, 2024:
- bias approximately zero
- Brier and Poisson improve substantially
- MAE/improvement fail

This diagnostic asks one specific question:
Can a convex blend retain the raw component's MAE advantage while taking enough
of the hurdle model's zero-vs-positive discrimination to satisfy the bias gate?

No new model is trained.

Candidate family
----------------
For each already-generated hurdle expected-count path:

    point = (1 - w) * raw_component + w * hurdle_expected_count

where:
    w = 0.000, 0.001, ..., 1.000

The two hurdle expected-count paths were already generated by the prior
pre-2025 hurdle diagnostic:
- unit positive severity
- training-data positive mean severity

Selection
---------
- blend weight selected using 2024 only
- 2025 is reporting only
- same frozen weight used on 2025
- no 2025 result can change the weight

Probability policy
------------------
This remains a point-only candidate. The existing production-calibrated P(1+)
path is unchanged, so Brier is evaluated on the existing production probability
path rather than re-tuned to the blend.

No production models, calibration files, thresholds, registry, selected-model
metadata, or manifests are modified.
